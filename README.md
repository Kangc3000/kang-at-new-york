## How to post 如何發文
1. Sign in to GitHub (a free account; reading needs no account). 登入 GitHub（免費帳號；只看不用登入）。
2. Open **Discussions** → pick a category → **New discussion**. 開啟 Discussions → 選分類 → New discussion。
3. Any language is welcome: 中文 · English · 日本語 · 한국어 · Español. 歡迎用任何語言。

## Categories 分類
- 📢 **公告 Announcements** — news from Kang (read-only)
- 💬 **綜合討論 General** — anything about the stories and games
- 🎮 **風雷源起 Rising Wind and Thunder** — the game: discussion, 算題求助 puzzle help, 建議 ideas
- 🐛 **問題回報 Bug reports** — something broken? Say which game, device/browser, language, and what happened
- 📖 **小說 Novels** — the books
- 🙋 **問與答 Q&A** — questions with a marked answer

New games and apps get their own category when they appear.

## Rules 規則
Be kind. No spam, no harassment, no spoilers in titles (use spoiler tags or the 劇情討論 label). Moderators may edit, lock or remove posts. 友善相待；不灌水、不騷擾；標題不劇透。版主得編輯、鎖定或移除貼文。

This repository holds only the board and this page — no game code.
